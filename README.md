# 校小撰——校園文案生成器

一個專為校園場景設計的智能文案生成微信小程序，幫助學生、教師和校園工作者快速生成各類校園文案。

## 功能特色

### 📝 文案生成
- **校園官方場景**：導員通知、校園公告、社團事務
- **社交平台**：小紅書、朋友圈、抖音、二手交易
- **圖片導入生成**：支持圖片識別，智能生成相關文案

### ✨ 文案優化
- 多種優化風格：專業、創意、情感、幽默
- 智能優化重點：語法修正、風格提升、結構優化、詞彙豐富
- 目標受眾適配：學生群體、教師群體、一般公眾

### 📚 文案瀏覽
- 關鍵詞搜索和圖片導入搜索
- 多維度篩選：全部、已生成、已優化、收藏
- 智能排序：時間、標題、類型

### 🎨 主題切換
- 淺色主題：簡潔清爽
- 深色主題：護眼舒適
- 彩色主題：活力個性

## 技術架構

### 前端技術
- **框架**：微信小程序原生開發
- **樣式**：WXSS + CSS3
- **交互**：JavaScript ES6+
- **狀態管理**：本地存儲 + 全局數據

### 項目結構
```
├── app.js                 # 小程序入口文件
├── app.json              # 全局配置
├── app.wxss              # 全局樣式
├── pages/                # 頁面目錄
│   ├── index/            # 首頁
│   ├── generate/         # 文案生成
│   ├── optimize/         # 文案優化
│   ├── browse/           # 文案瀏覽
│   └── settings/         # 設置頁面
├── utils/                # 工具類
│   ├── api.js           # API服務
│   ├── storage.js       # 存儲服務
│   └── theme.js         # 主題管理
└── images/              # 圖片資源
```

## 核心功能實現

### 1. 文案生成系統
- 場景化模板：針對不同校園場景提供專業模板
- 智能參數：支持主題、關鍵詞、風格、字數等參數
- 實時預覽：生成過程中提供實時反饋

### 2. 文案優化引擎
- 多維度優化：語法、風格、結構、詞彙
- 智能分析：根據原文內容智能推薦優化方案
- 對比展示：優化前後對比，優化說明詳解

### 3. 智能搜索系統
- 關鍵詞搜索：支持模糊匹配和精確搜索
- 圖片識別：上傳圖片自動識別內容並生成相關文案
- 多維度篩選：按類型、時間、收藏狀態篩選

### 4. 主題系統
- 多主題支持：淺色、深色、彩色三種主題
- 動態切換：實時切換主題，無需重啟
- 個性化：支持自定義主題配置

## 用戶體驗設計

### 界面設計
- **簡潔大方**：採用卡片式設計，層次分明
- **色彩搭配**：根據主題動態調整色彩方案
- **響應式佈局**：適配不同屏幕尺寸

### 交互設計
- **直觀操作**：一鍵生成，快速優化
- **智能提示**：操作引導和錯誤提示
- **快捷功能**：快速搜索標籤，一鍵分享

### 性能優化
- **本地存儲**：重要數據本地緩存
- **懶加載**：圖片和內容按需加載
- **緩存策略**：智能緩存管理

## 開發指南

### 環境要求
- 微信開發者工具
- Node.js 14+
- 微信小程序開發賬號

### 安裝步驟
1. 下載微信開發者工具
2. 導入項目文件夾
3. 配置小程序AppID
4. 編譯運行

### 配置說明
- 修改 `app.js` 中的 `apiBaseUrl` 為實際API地址
- 配置 `app.json` 中的頁面路徑和權限
- 添加必要的圖片資源到 `images/` 目錄
